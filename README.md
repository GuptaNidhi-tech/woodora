 Woodora – Furniture Inspiration Website

Woodora is a furniture inspiration website created using HTML5 and CSS3. The main focus of this project was to build a clean, visually appealing, and responsive layout that adapts to different screen sizes.

Features
- Responsive website layout
- Clean and modern user interface
- Furniture-inspired design
- Adaptable layouts for different screen sizes

Technologies Used
- HTML5
- CSS3

 What I Learned
- Creating responsive web layouts
- Working with CSS styling and positioning
- Improving layout adaptability across different screen sizes
- Structuring web pages using HTML5
